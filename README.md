# NBA Player Performance & Contract Valuation Model

A quantitative sports analytics engine that calculates composite player productivity indices and evaluates contract efficiency across NBA roster cap hits.

## Key Analytics
- **Productivity Index (PI):** Standardized metric balancing box volume (PPG, RPG, APG) alongside advanced player efficiency (PER).
- **Fair Market Valuation:** Computes statistical baseline monetary valuation relative to positional payroll allocations.
- **Contract Surplus / Drag:** Identifies roster bargains vs cap-inefficient contracts to inform salary cap asset management.

## Tech Stack
- **Language:** Python 3.x
- **Focus:** Sports Analytics, Quantitative Modeling, Valuation Algorithms
